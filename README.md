# Chaya 🌙

A desktop focus companion built with Python and Tkinter.

## Features

- Focus timer
- Break timer
- Motivational dialogue
- Always-on-top desktop companion
- Aesthetic interface

## Built With

- Python
- Tkinter
- Pillow

## AI Disclosure

This project was created as a personal learning project.

I used AI (ChatGPT) extensively to help generate, explain, and debug code while learning Python. The overall concept, design decisions, feature ideas, testing, and iteration were my own.

This repository represents my learning process and my interest in building software from ideas.

## Running

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```
